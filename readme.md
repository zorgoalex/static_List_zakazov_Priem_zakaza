полноценную систему управления заказами для менеджера мебельного производства.

## 🏗️ **Архитектура системы**

Код разбит на модули согласно требованиям:
- **index.html** - основная разметка
- **style.css** - стили (встроены в HTML)
- **demo-data.js** - обширный демо-датасет
- **filters.js** - система фильтрации и сортировки
- **table.js** - управление таблицей и пагинацией
- **popups.js** - модальные окна и формы
- **main.js** - основная логика приложения

## 📊 **Основные возможности**

### **1. Список заказов**
- **Мощная фильтрация**: по дате, клиенту, статусу, приоритету
- **Сортировка**: по всем колонкам с визуальными индикаторами
- **Статистика**: общее количество, в работе, готовые, общая сумма
- **Пагинация**: удобная навигация по страницам
- **Действия**: просмотр, редактирование, удаление заказов

### **2. Создание/редактирование заказов**
- **Автодополнение клиентов** с историей телефонов
- **Полная информация о заказе**: даты, суммы, скидки
- **Материалы и характеристики**: основной материал, кромки, пленки, фрезеровка
- **Управление деталями**: добавление, редактирование, удаление деталей
- **Автоматический расчет** площадей и количества деталей
- **Загрузка файлов**: чертежи, CAD, PDF

### **3. UX/UI особенности**
- **Современный дизайн** с градиентами и тенями
- **Адаптивность** для десктопа и мобильных устройств
- **Цветовая индикация** статусов и приоритетов
- **Уведомления** об успешных операциях
- **Валидация форм** с понятными сообщениями об ошибках

## 🔧 **Модули и их ответственность**

### **1. index.html**
- Основная HTML-разметка
- Структура страниц (список заказов, форма заказа)
- Модальные окна
- Подключение всех JS модулей

### **2. style.css**
- Современные стили с градиентами
- Адаптивный дизайн (desktop + mobile)
- Анимации и transitions
- Цветовая индикация статусов

### **3. demo-data.js**
- 50 заказов разных типов и статусов
- 10 клиентов с контактами
- Материалы, кромки, пленки, фрезеровка
- Вспомогательные функции форматирования

### **4. filters.js**
- Класс `FiltersManager`
- Фильтрация по дате, клиенту, статусу, приоритету
- Сортировка с визуальными индикаторами
- Обновление статистики

### **5. table.js**
- Класс `TableManager`
- Рендеринг таблицы заказов
- Пагинация с навигацией
- Обработка действий (просмотр, редактирование, удаление)

### **6. popups.js**
- Класс `OrderFormManager`
- Создание и редактирование заказов
- Управление деталями заказа
- Автодополнение клиентов
- Валидация форм

### **7. main.js**
- Класс `App` - основной контроллер
- Инициализация всех модулей
- Навигация между страницами
- Система уведомлений
